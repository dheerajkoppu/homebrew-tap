# Homebrew tap

Homebrew casks for apps by [Dheeraj Koppu](https://github.com/dheerajkoppu).

## Tally

[Tally](https://dheerajkoppu.github.io/tally/) is a free, open-source system monitor for Mac that adds every helper process to the app it works for.

```bash
brew install --cask dheerajkoppu/tap/tally
```

Tally needs macOS 15 Sequoia or later. It updates itself from **Tally › Check for Updates…**, so `brew upgrade` leaves it alone unless you pass `--greedy`.
